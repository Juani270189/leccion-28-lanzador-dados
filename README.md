# Lanzador de dados

Proyecto realizado durante la lección 28 del curso OpenBootcamp.

## ¿Qué hace?

Es una pequeña aplicación web que permite lanzar un dado pulsando un botón. El resultado se genera aleatoriamente mediante JavaScript.

## ¿Qué he aprendido?

- Crear una página interactiva con HTML y JavaScript.
- Modificar el comportamiento de una aplicación.
- Utilizar la consola del navegador para detectar errores.
- Corregir un error de JavaScript.

## Error encontrado

Provoqué el error `ReferenceError: resultados is not defined` al escribir incorrectamente el nombre de una variable.

Lo solucioné cambiando `resultados` por `resultado`.
